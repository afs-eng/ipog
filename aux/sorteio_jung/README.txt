SORTEIO DO SEMINÁRIO — JUNG

1. Instale Python 3 no Windows.
2. Abra o PowerShell na pasta do arquivo sorteio_jung.py.
3. Instale a biblioteca para exportar PDF:
   py -m pip install reportlab
4. Execute:
   py sorteio_jung.py
5. Digite os quatro nomes e clique em REALIZAR SORTEIO.
6. Clique em Salvar resultado em PDF para gerar o comprovante.

A interface usa Tkinter, que geralmente já vem com Python no Windows.
