VIDEOAULA DO ESTUDO DIRIGIDO - INTRODUÇÃO À PSICOLOGIA N2

1. Abra Videoaula_Estudo_Dirigido_Psicologia_Questoes_Explicadas.html no Google Chrome ou Microsoft Edge.
2. Clique em Assistir. É necessária internet para ouvir a narração Lucilene, que está hospedada externamente.
3. Use os capítulos para estudar as questões 1, 2, 3, 4, 5, 7 e 8.
4. Consulte o Guia_de_Estudo_Questoes_Respondidas_Psicologia_N2.pdf para escrever respostas próprias.

A personagem à esquerda é fixa e de corpo inteiro; os elementos didáticos se movimentam apenas à direita.
O estudo dirigido original não inclui questão 6.

O arquivo HTML é um reprodutor interativo (não é arquivo MP4). Para um MP4 único com a voz embutida, seriam necessários arquivos locais dos três áudios da Lucilene.
